# Public Portfolio Engineering Rules

- Correctness, reproducibility, restraint, and honest claims matter more than feature count.
- Protect behavioral changes with deterministic tests and keep external model calls mocked.
- Never log prompts, model responses, credentials, or private conversation content.
- Do not invent capabilities, adoption, benchmarks, screenshots, or production-readiness claims.
- Do not add infrastructure or frameworks without a concrete requirement.
- Do not commit local databases, vector indexes, model caches, credentials, or generated bytecode.
- Keep the README synchronized with executable behavior and supported ports.
- Run backend tests and the frontend production build before claiming completion.
